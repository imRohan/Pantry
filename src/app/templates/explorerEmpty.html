Welcome to Pantry Getting Started

You can manage your data through our Web Dashboard or via the API. Every feature available in the dashboard is fully accessible through the API.

Ready? Let’s create your first basket.

The API is built on REST principles and accepts JSON-encoded request bodies. To get started, create your first basket in your pantry by following our API documentation.

Alternatively, you can click on 'Create Basket' from the sidebar to the left to create your first basket.

TL;DR

Paste a snippet from below to create your first basket using our API, and then read the docs.

Curl

Unix/Linux

curl -XPOST -H "Content-type: application/json" -d '{ "key": "value" }' '{{apiPath}}/pantry/{{this.pantryId}}/basket/testBasket'

Powershell

Windows

Invoke-WebRequest -Uri '{{apiPath}}/pantry/{{this.pantryId}}/basket/testBasket' -Method POST -ContentType 'application/json' -Body '{ "key": "value" }'
