Effortless

A better JSON storage solution

CRUD your data on the cloud in just 2 minutes either by using our API or dashboard. Perfect for small projects and hackathons!

Generous Storage Limit

Your Pantry can have 100 baskets (JSON objects), each with a max size of 1.44mb. That's a lot of JSON, and we think it's a great starting point for developers.

Supports JSON Schema

Data integrity is the backbone of any good project. So stop worrying about malformed data breaking your frontend by enabling optional JSON schema validation for each of your baskets.

Simple API

We've built a very straightforward and easy-to-use API which you can use to CRUD your Pantry's baskets. Simple and intuitive - that's the goal.

Generate Public URLS

Expose your data to users by using public urls. These are "share anywhere" read only paths that protect your Pantry's ID and Basket details.

Powerful Dashboard

We also offer a slick dashboard which you can use to interact with your Pantry's baskets. This intuitive interface is especially helpful when debugging your application.

100% Open Source

This project is open-source and supported by a wonderful group of developers who continue to improve the platform.
